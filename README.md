# Canvas Mind Map

**把 Markdown 笔记变成可折叠、可跳转、可自由排布的思维导图。**

Canvas Mind Map 是一个 Obsidian 插件。它将笔记中的标题层级转换为原生 Canvas 卡片，让你在一张画布上浏览文章结构、展开细节，并跳回原文继续阅读。

## 功能亮点

- **一键生成**：从 Markdown 笔记卡片或包含标题的文本卡片生成导图，支持 H1–H6 标题。
- **两种内容模式**：仅标题模式适合梳理结构；含正文模式适合边看结构边阅读章节。
- **七种布局**：中心向四周、左右双侧、上下双侧，以及向右、向左、向下、向上的单向树。生成后可随时切换。
- **逐层展开**：收起整个分支、展开下一级，或显示到指定层级，让复杂笔记保持清晰。
- **链接原笔记**：笔记来源的标题卡片链接到对应章节；文本来源直接显示标题。
- **按层设置外观**：自定义中心和各层卡片的宽度、高度、颜色与自动高度，也可单独调整节点。
- **从原文刷新**：笔记结构变化后更新导图，保留可匹配节点的手动编辑；涉及移除节点时先确认。
- **原生 Canvas 体验**：保留卡片编辑、额外连线、撤销与重做。导图随画布保存，停用插件后卡片仍然保留。

## 安装

目前可手动安装：

1. 获取 `main.js`、`manifest.json` 和 `styles.css` 三个插件文件。若仓库尚未提供下载包，可按下方步骤从源码构建。
2. 在笔记库中创建 `.obsidian/plugins/canvas-mind-map/` 文件夹，将三个文件放入其中。
3. 重新加载 Obsidian，在「设置 → 第三方插件」中启用 **Canvas Mind Map**。

需要 Obsidian **1.7.7 或更高版本**。如果此前使用 Enhanced Canvas 的思维导图功能，请先停用旧插件；旧导图元数据暂不兼容。

## 快速开始

1. 打开一个 Canvas，放入 Markdown 笔记，或创建含有标题的文本卡片。
2. 选中卡片，右键选择 **生成可折叠思维导图**。也可以通过命令面板执行同名命令。
3. 选择「仅标题」或「含正文」，再选择布局，点击「生成」。插件会记住上次的选择。
4. 点击节点下方的 **＋ / −** 展开或收起分支。

首次默认使用「仅标题 + 中心向四周」，生成后显示到第 2 层。只有一个顶层标题时，该标题会成为中心；多个顶层标题则围绕笔记中心展开。生成会替换来源卡片，并将原有外部连线接到新中心，可通过撤销恢复。

### 调整导图

在导图节点上打开右键菜单，可以：

- **显示到第 N 层**，控制当前展示的细节。
- **返回中心**，快速定位导图。
- **切换布局 / 重新排列**，整理整棵树的位置。
- **设置此节点外观**，或将设置页中的层级模板应用到整棵树。
- **从原笔记刷新**，同步标题结构的变化。

每棵导图独立保存布局。切换布局会重新排列节点；普通展开会保留已有卡片的位置。刷新时，如果无法匹配旧节点（例如标题被删除、改名、跨父级移动或出现重名），插件会显示变更确认，请检查后再应用。

## 从源码构建

需要 Node.js 和 npm：

```sh
npm install
npx tsc --noEmit
npm run dev
```

开发构建会生成 `main.js` 并持续监听源码变化。将生成的文件与 `manifest.json`、`styles.css` 一起复制到插件目录；结束监听可按 `Ctrl+C`。
