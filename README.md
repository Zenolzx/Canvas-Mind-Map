# Canvas Mind Map

独立的 Obsidian Canvas 思维导图插件。由 Enhanced Canvas 的思维导图功能迁移，保留原 MIT 许可证。

## 安装

将本目录中的 `main.js`、`manifest.json`、`styles.css` 复制到笔记库的 `.obsidian/plugins/canvas-mind-map/`，重新加载 Obsidian 后启用 **Canvas Mind Map**。按本项目使用方式，请禁用旧 Enhanced Canvas 插件。

## 使用

在 Canvas 中选中一个 Markdown 笔记卡片或包含标题的文本卡片，右键选择 **生成可折叠思维导图**（也可使用同名命令）。在生成窗口选择：

- 节点内容：仅标题 / 含正文。笔记来源的标题链接加粗，可跳回原笔记；文本来源显示标题文字。
- 布局：中心向四周、左右双侧、上下双侧、向右、向左、向下、向上。

首次默认仅标题和中心向四周；此后记住上次生成选择。单个顶层标题会提升为中心。原卡片由紧凑中心替代，原文来源保存于导图元数据，原外部连线重接到中心。

生成后默认显示到第 2 层。节点下方按钮控制折叠；右键或命令可展开、收起、显示到指定层、返回中心、重排、切换布局、刷新原笔记、应用层级模板、设置当前节点外观。

每棵导图保存自己的布局。切换布局会重排节点，保留内容、连线、样式、折叠状态，并记录为一次 Canvas 撤销操作。普通展开仅安排新显示节点，保留已有节点位置。

设置页提供中心到第 6 层的宽高、自动高度和颜色模板。刷新原笔记会保留能匹配的节点及手工修改；涉及无法匹配的标题和额外连线时，会先显示变更确认。

不包含标签导入、发送到 Canvas、笔记属性同步等功能。不读取旧插件的思维导图元数据。

## 开发与验证

依赖版本固定在 `package.json`；运行 `npm install` 安装。当前目录已复制本机可用依赖。

- `npx tsc --noEmit`：类型检查。
- `npm run dev`：开发构建和监听，输出 `main.js`。

Obsidian 与 CodeMirror 保持外部依赖。无需修改原 Enhanced Canvas 项目。

### 需要在 Obsidian 中验证

1. 笔记与文本来源分别生成仅标题和含正文模式；验证标题跳转与自动高度。
2. 切换 7 种布局，验证撤销/重做、保存重开后布局与折叠状态。
3. 手动移动和修改卡片后折叠再展开，确认已有卡片位置和样式保留。
4. 修改源笔记后刷新，验证删除确认、保留手改内容和外部连线。
5. 弹出窗口中操作导图；禁用插件后确认节点全部显示、按钮移除。

## 实现约定

- `main.ts` 只提供独立插件壳、设置与 Canvas 菜单接入；所有原型补丁使用 `registerLazyPatcher`，成功后移除重试监听器，卸载时还原补丁。
- `src/CanvasMindmap.ts` 负责生成窗口、菜单、折叠显示、刷新、自动高度与样式。DOM 观察器和动画帧使用节点所属窗口。
- `src/MindmapModel.ts` 负责 Markdown 标题树、布局与样式数据操作。新命名空间为 `canvasMindMap` / `canvasMindMapRoot`；根节点的 `layout` 保存布局。
- 折叠只隐藏 DOM，不从 Canvas 数据中移除节点或连线。编辑前深拷贝 Canvas 数据，再通过 `setData` 和 `requestSave(false)` 提交。
- 放射布局使用同心环与分支扇区；方向树按卡片尺寸和子树跨度排布，双侧分支按跨度平衡；碰撞检查只移动候选节点。显式布局切换才重排整棵树。
