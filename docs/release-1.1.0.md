# Canvas Mind Map 1.1.0

Canvas Mind Map 1.1.0 expands the ways you can read source files and explore ideas in Obsidian.

## Highlights

- Open DOCX and PDF files in Organic view. DOCX headings and supported plain-text body sections can be edited; PDFs remain read-only. Native Canvas mind maps can also be generated from DOCX and PDF file cards.
- Switch Composer between Structured and Sketch modes. Arrange headings and independent notes freely, connect objects, and add arrow, lasso, highlighter, or text annotations. Sketch objects stay in the Composer draft and are not inserted into the exported Markdown note.
- Choose from four bundled wallpapers for Composer, Organic, and Native Canvas mind maps, or keep the default plain background.
- Refine Composer animations, node interactions, the Create Note dialog, and Organic toolbar layout and localization.

## Upgrade notes

- Existing Composer drafts remain supported; Sketch data is saved with the draft. If independent Sketch objects remain after creating a note, the Composer draft is retained.
- Install or update through Obsidian Community Plugins. For manual installation, download `main.js`, `manifest.json`, and `styles.css` from this release into `.obsidian/plugins/canvas-mind-map/`, then reload Obsidian.
- Requires Obsidian 1.7.7 or later.

# Canvas Mind Map 1.1.0（简体中文）

本次更新扩展了 Obsidian 中的文件阅读和自由构思方式。

## 主要更新

- Organic 支持打开 DOCX 和 PDF。DOCX 的标题和受支持的纯文本正文可编辑；PDF 为只读。原生 Canvas 也可从 DOCX、PDF 文件卡片生成导图。
- Composer 新增结构／手稿模式切换。手稿模式支持自由摆放标题和便签、连接对象，以及箭头、圈选、荧光笔和文字批注。手稿对象保存在 Composer 草稿中，不写入导出的 Markdown 笔记。
- Composer、Organic 与原生 Canvas 可选用四种内置壁纸，也可继续使用默认纯色背景。
- 优化 Composer 动画、节点交互和创建笔记弹窗，并改进 Organic 工具栏布局及本地化。

## 升级说明

- 现有 Composer 草稿继续受支持；手稿数据随草稿保存。创建笔记后若仍有独立手稿对象，Composer 草稿会保留。
- 可通过 Obsidian 第三方插件市场更新。手动安装请下载本 Release 的 `main.js`、`manifest.json`、`styles.css`，放入 `.obsidian/plugins/canvas-mind-map/` 后重启 Obsidian。
- 需要 Obsidian 1.7.7 或更高版本。
